# AstrBot 群杯子插件

一个基于 AstrBot 框架的趣味群互动插件，每天在群成员中随机抽取一名「群杯子」，并维护历史排行榜。

## 功能概览

- **每日抽取**：每天每个群随机抽取一名群友作为当天的「群杯子」，全天唯一不重复
- **权限控制**：仅群主或群管理员可触发抽取，其他人使用会收到权限不足提示
- **私聊拦截**：私聊中使用会提示无法使用
- **历史排行榜**：记录所有历史抽取结果，按被抽中次数排名，展示前十名

## 指令列表

| 指令 | 说明 | 权限要求 |
|------|------|----------|
| `^群杯子` | 随机抽取今日群杯子；若今日已抽取则回复已有结果 | 群主/管理员 |
| `^群杯子排行` | 查看本群群杯子历史排行榜（前十名） | 全体群成员 |

> 指令前缀 `^` 取决于 AstrBot 全局配置中的指令前缀设置。如果你的前缀不是 `^`，请将上述指令中的 `^` 替换为你配置的前缀。

## 使用示例

### 抽取群杯子

群主或管理员发送：
```
^群杯子
```

首次抽取时，机器人会从群成员中随机选择一名（排除机器人自身），并 At 该成员：
```
🎉 今天的群杯子已经诞生！
恭喜 @某人（昵称）成为今天的群杯子！
```

当天再次发送 `^群杯子`，不会重复抽取，仅回复已有结果：
```
今天的群杯子已经诞生了！
今天的群杯子是：某人（123456789）
```

非管理员发送时：
```
权限不足，只有群主或群管理员可以使用此功能。
```

私聊发送时：
```
私聊无法使用此功能，请在群聊中使用。
```

### 查看排行榜

任意群成员发送：
```
^群杯子排行
```

机器人回复示例：
```
🏆 群杯子排行榜（前十名）

🥇 小明 - 5次
🥈 小红 - 3次
🥉 小刚 - 2次
4. 小华 - 1次
5. 小李 - 1次
```

若无历史记录：
```
本群还没有群杯子记录，快使用「群杯子」开始第一次抽取吧！
```

## 安装方式

### 方式一：通过 WebUI 安装

1. 将插件 zip 包上传或在 AstrBot WebUI 插件市场搜索安装
2. 在 WebUI 插件管理处点击「重载插件」

### 方式二：手动安装

1. 将插件文件夹解压到 `AstrBot/data/plugins/astrbot_plugin_group_cup/`
2. 在 WebUI 插件管理处点击「重载插件」或重启 AstrBot

## 配置说明

插件支持以下 WebUI 可视化配置项（在插件管理页面配置）：

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| 时区偏移 | int | 8 | 日期计算使用的 UTC 时区偏移（小时），默认东八区 |

## 数据存储

插件数据持久化存储在以下路径，更新插件不会丢失数据：

```
AstrBot/data/plugin_data/astrbot_plugin_group_cup/cup_data.json
```

数据文件结构：
```json
{
  "daily": {
    "群号": {
      "2025-01-15": {
        "user_id": "123456",
        "nickname": "群昵称"
      }
    }
  },
  "stats": {
    "群号": {
      "123456": 3
    }
  }
}
```

- `daily`：每日抽取记录，按群号和日期索引
- `stats`：被抽中次数统计，按群号和用户 ID 索引

## 环境要求

- AstrBot >= v4.15.0
- OneBot v11 协议端（如 NapCat、Lagrange.OneBot、go-cqhttp 等）
- Python >= 3.10

## 技术细节

- 使用 `asyncio.Lock` 保证并发安全，防止同一群多人同时触发导致重复抽取
- 权限检查双重校验：优先从消息事件 `sender.role` 读取，不可用时回退到 OneBot API `get_group_member_info` 查询
- 抽取结果使用消息链（`At` + `Plain`）发送，At 构造失败时自动回退为纯文本
- 显示名优先级：群名片 > QQ 昵称 > QQ 号
- 日期计算使用东八区时区（UTC+8），可通过配置项调整
